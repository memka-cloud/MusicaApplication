# Music App Client

Для запуска плеера выполните 2 простых шага:

1. **Обязательно установите VLC Media Player** (если его еще нет на ноутбуке). 
   Скачайте официальную 64-битную версию по ссылке: https://videolan.org
2. Скачайте файлы репозитория и запустите файл **`2_Запустить_Плеер.bat`**.
